# Anleitung zur Datenlöschung

Stand: [[Datum]]

NEEDL ist eine Software für Tattoo-Studios. Wenn Sie über ein Lead-Formular auf Facebook oder
Instagram oder per WhatsApp mit einem Studio in Kontakt getreten sind, das NEEDL nutzt, werden
Ihre Daten im Auftrag dieses Studios gespeichert.

## So lassen Sie Ihre Daten löschen

**1. WhatsApp-Kontakt beenden:** Senden Sie im WhatsApp-Chat mit dem Studio die Nachricht
**„STOP“**. Sie erhalten danach keine weiteren Nachrichten mehr.

**2. Löschung beim Studio verlangen:** Bitten Sie das Studio per WhatsApp, E-Mail oder
persönlich, Ihre Daten zu löschen. Das Studio löscht Ihren Kontakt in NEEDL; dabei werden Name,
Telefonnummer, E-Mail-Adresse, Chatverlauf, Tattoo-Idee und von Ihnen gesendete Bilder entfernt.

**3. Löschung direkt bei uns anfragen:** Schreiben Sie an **datenschutz@needl-booker.de** mit
dem Betreff „Datenlöschung“ und nennen Sie die Telefonnummer, mit der Sie das Formular
ausgefüllt bzw. das Studio angeschrieben haben, und – falls bekannt – den Namen des Studios. Wir
leiten Ihre Anfrage an das zuständige Studio weiter und sorgen dafür, dass sie innerhalb eines
Monats bearbeitet wird. Zur Bestätigung erhalten Sie eine Antwort per E-Mail.

## Automatische Löschung

Kontakte, aus denen keine Beratung und kein Termin entstanden ist, löscht NEEDL **10 Monate
nach der letzten Aktivität automatisch**. Sicherungskopien werden nach 14 Tagen überschrieben.

## Was nicht sofort gelöscht werden kann

Haben Sie bei einem Studio einen Tattoo-Termin wahrgenommen, kann das Studio gesetzlich
verpflichtet sein, Angaben für Rechnungen und Buchhaltung aufzubewahren. Diese Angaben werden
gesperrt und nach Ablauf der Fristen gelöscht.

## Mitarbeitende eines Studios

Wenn Sie als Mitarbeiterin oder Mitarbeiter eines Studios einen Zugang zu NEEDL hatten, wenden
Sie sich an den Admin Ihres Studios oder an datenschutz@needl-booker.de.

Weitere Informationen finden Sie in unserer Datenschutzerklärung unter
needl-booker.de/datenschutz.
